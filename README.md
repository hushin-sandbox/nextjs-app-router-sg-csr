# Next.js 15 で SG と CSR を組み合わせたサンプルコード

Next.js 15 で Static Generation (SG)と Client-Side Rendering (CSR)を組み合わせたサンプル

## Getting Started

First, run the development server:

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## SG build and start

```bash
npm run build
npm start
```
